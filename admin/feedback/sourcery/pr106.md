### Overall-#1: Hard-coded absolute paths in `01-branch-setup-and-doc-curation.md`

**Comment:** Task instructions hard-code local absolute paths (e.g., `/Users/cdwilson/...`); consider rewriting these using repo-root–relative paths or placeholder variables so they're reusable by other contributors and future you on different machines.

- The `cp` commands at lines 80 and 119 embed `/Users/cdwilson/Projects/dev-infra/worktrees/docs-skill-template-separation-research/...` as literal paths.
- Personal username appears in a publicly visible feature directory.
- If anyone treats this doc as a template for similar curation work, they'd need to translate paths.

**Sourcery is missing context:**

**Verdict — Defer (initial) → Fixed inline (user override):** Initial verdict was to defer pending a project-wide convention sweep. User overrode: "I would actually like to not have the absolute paths in the repo though." The privacy/info-leak angle (personal username in a public repo) outweighed the consistency argument.

**Action taken:** Replaced both `/Users/cdwilson/Projects/dev-infra/worktrees/docs-skill-template-separation-research/...` paths with `../docs-skill-template-separation-research/...` (relative from this worktree), and updated the stale "(use absolute paths to avoid ambiguity)" parenthetical to reference the worktree naming convention from `AGENTS.md`.
